# Project-Athena
## Custom Cybersecurity Workstation Build
Project Athena is a hands-on custom PC Build desigend to create a powerful, upgradable workstation for cybersecurity labs, virtualization, technical learning, and future projects.
## Project Goals
- Research and select compatible PC hardware
- Build and configure the system from the ground up
- Document hardware installation and configuration
- Learn BIOS/UEFI configuration and system setup
- Install and configure the operating system
- Test system stability and performance
- Troubleshoot hardware and software issues encountered during the build
- Create a virtualization environment for cybersecurity labs
- Document the entire process as a technical portfolio project
## Skills Demonstrated
This project will document practical experience with:
- PC hardware and component compatability
- Motherboard installation and configuration
- CPU, RAM, storage, GPU, and power installation
- ESD-safe hardware handling
- BIOS/UEFI configuration
- Operating system installation
- Drivers and firmware
- Troubleshooting and testing
- Virtualization
- Cybersecurity lab configuration
- Git and GitHub version control
- Technical documentation
